## 💻 About me

Hi there! 👋 I'm a Senior Full Stack Developer with 5 years of experience building scalable, resilient, and well-structured applications. I thrive on clean architecture, design patterns, and writing mature code that stands the test of time.
My core stack is built around Angular, TypeScript, and NestJS, but I love exploring new technologies and constantly expanding my toolkit (currently diving into Go, Python, and native iOS development with Swift). Beyond software, I'm passionate about electronics, writing, and photography.

🛠️ **What I value:** Single responsibility, testability, and long-term scalability.

🧠 **My philosophy:** Understanding the why behind the tools we use, not just making things work.
